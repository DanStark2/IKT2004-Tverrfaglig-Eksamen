# Brukerveiledning

Kort brukerfokusert veiledning for å kjøre og teste prosjektet lokalt.

1. Backend
   - Gå til `src/backend`.
   - Kjør `npm install` for å installere avhengigheter.
   - Start server med `npm start`.

2. Frontend
   - Åpne `src/frontend/index.html` i en nettleser.
   - Frontend kommuniserer med backend på `http://localhost:3000`.

Tips:
- Hvis du bruker VS Code, installer Live Server for å serve frontend enkelt.
