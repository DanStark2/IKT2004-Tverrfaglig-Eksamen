IKT2004 - Eksamen

Main Admin panel

Hva er dette?

Dette er en enkel eksamensapplikasjon for IKT2004. Den viser hvordan en liten webapplikasjon kan bruke:

  • En frontend med HTML, CSS og JavaScript
  • En Express backend med et API
  • Lagring av produkter i en lokal database

Brukeren kan registrere produkter, og admin kan deretter se listen over lagrede produkter.

Trykk på Admin panel i menyen for å se produktlisten.
