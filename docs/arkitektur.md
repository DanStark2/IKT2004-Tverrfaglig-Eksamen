# Arkitektur

Beskrivelse av arkitektur for prosjektet.

- Frontend: Enkel statisk side (`index.html`, `style.css`, `script.js`).
- Backend: Node.js med Express som serverer API og statiske filer.
- Database: Relasjonsdatabase med SQL-schema i `database/schema.sql`.

Tips:
- For større prosjekter kan du legge til en services-lag og autentisering.
